# Security Policy

## Supported versions

The active development scope is 1.8.8, 1.21.11, 26.2, and 26.3. No BeefMC release is declared security-supported yet. Check the [BeefMC releases](https://github.com/Sawlyer/BeefMC/releases) and release notes for build-specific status. Leaf labels its 26.2 and 26.3 builds as testing-only.

## Reporting a vulnerability

Do not post an exploitable vulnerability, remote crash, or item-duplication issue in a public issue.

Use GitHub's private vulnerability reporting for [Sawlyer/BeefMC](https://github.com/Sawlyer/BeefMC/security/advisories/new). If that feature is unavailable, contact the repository owner privately through GitHub and do not publish the details.

For non-sensitive issues, open a BeefMC issue with the build, Minecraft version, and reproduction steps.
